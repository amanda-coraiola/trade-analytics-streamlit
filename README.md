# 📊 Trade Analytics & Sales Dashboard

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://trade-analytics-app-cyqzmhuqws89y8llgwyp5t.streamlit.app/)

> Aplicação web analítica e interativa desenvolvida em Python para o monitoramento de performance comercial, faturamento, metas e indicadores críticos de ruptura no setor de Varejo e Trade Marketing.

---

## 🎯 Sobre o Projeto
Este projeto simula um ecossistema analítico voltado para equipes comerciais e de gestão, permitindo cruzar dados de vendas por canais, regiões e categorias de produtos com alta interatividade. 

A solução demonstra a capacidade de transformar dados tabulares em uma aplicação web executiva (*Data App*) de forma ágil e escalável, sem a necessidade de infraestrutura pesada de BI tradicional.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Python**: Linguagem principal para processamento e lógica da aplicação.
* **Streamlit**: Framework para construção e deploy da interface web interativa.
* **Pandas**: Manipulação, limpeza e agregação de dados.
* **Plotly**: Criação de gráficos dinâmicos e responsivos.
* **Streamlit Community Cloud**: Hospedagem e entrega contínua na nuvem.

---

## 📈 Principais Funcionalidades do App
* **Filtros Dinâmicos Laterais:** Segmentação instantânea por Região, Canal de Vendas e Portfólio de Produtos.
* **Cartões de KPIs Executivos:** Acompanhamento em tempo real de Faturamento Total, Meta Prevista, % de Atingimento e Taxa Média de Ruptura.
* **Gráficos de Desempenho:** 
  * *Gráfico de Barras:* Faturamento segmentado por canal de distribuição.
  * *Gráfico de Rosca (Donut):* Participação percentual de faturamento por região.
  * *Gráfico de Linhas:* Evolução temporal comparativa entre faturamento real e metas estabelecidas.
* **Exportação de Dados:** Visualização em tabela detalhada e botão para download direto dos dados filtrados em formato CSV.
